Scan messages: what they mean and what to do

The scan log reports what the scan found. This page says what to do about the lines that need it. Links to /files/… open the files the scan wrote.

Regions

No default region configured; defaulting to us-east-1.
The Regions box was empty and this account has no saved region list yet. Type the regions to scan into the Regions box, or tick All regions.
Regions: … - the saved list for this account, from DATE
The scan covered the regions where earlier scans of this account found resources. Tick All regions to look everywhere.
Saved as this account's default regions: … (added to the saved list; none removed)
A scan of named regions only adds to the saved list. Only an All regions scan replaces it, so a region you emptied stays on the list until you run one.

What the scan could not see

ERR next to a resource type · Coverage: N denied · N lookup(s) failed and are not in the report
The credential lacks a read permission, or AWS returned an error. The resource type is left out of the report. The "Scan coverage" section of the grouping audit lists each failed call. To grant the permissions, update the IAM role or user behind the credentials file the app was started with, as iam/README.md in the repository describes.
Billing coverage: N unsupported, … - services the scan does not cover
The bill has charges for services this tool does not scan. The section "What you are paying for that this report does not cover" in the grouping audit names them.

Cost

Cost: Cost Explorer not queried (turned off for this scan)
Skip cost lookup was ticked. Scan without it to get cost figures (about $0.01 per request).
Cost: Cost Explorer unavailable (…)
Usually a missing ce:GetCostAndUsage permission; see iam/README.md.

Projects

N link(s) crossed a project boundary and were NOT merged
Two projects are linked, but each has its own tag or rule, so they stay separate. "Links that crossed a project boundary" in the grouping audit lists them.
N name(s) could group resources that nothing else connects (…)
These words appear in several resource names that have no other link between them. "Names that could group things" in the grouping audit lists which resources each word would join. The web app cannot create a name rule yet; for now, select those resources in the Resources tab and make them a project by hand.
N project(s) with a default name
These projects are named after a tag value, a rule or one of their members. Give any of them a name in the Projects tab.
Saved name "…" not applied: no project holds 40% of its resources
The resources that name was saved for have changed too much to match a project. The Projects tab marks it as not applied; rename it or forget it there.

Graph and audit

N supporting resource(s) contracted away
IAM roles, log groups, security groups and similar are hidden from the graph and their links drawn through. Tick Every resource in the Graph tab to draw them.
Audit: N oversized project(s), …
The grouping pass checking itself. Details are in the grouping audit.
